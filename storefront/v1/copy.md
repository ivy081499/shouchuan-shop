```
一顆一顆挑的天然石手串，戴在平常的日子裡。
```

## 商店簡介（關於我們）

```
平凡生活是一間一個人的工作室。

我到各地的散珠商家挑珠子，一顆一顆看過顏色、透度和大小，
再自己編成手串。沒有機器代工，所以每一條都有些微的不同——
珠子是天然的石頭，本來就不會兩顆一模一樣。

我做的手串不是拿來供著的，是戴在平常日子裡的東西：
上班、買菜、發呆、洗手的時候會碰到水的那種平常。
所以我在意的是它耐不耐戴、繩子會不會鬆、珠子會不會刮手，
而不是它有什麼功效。

如果你也喜歡這種不特別、但每天都在的東西，歡迎看看。
```

## 購物說明（購物須知）

```
【關於下單】

商品都是現貨，下單後我會盡快為你確認。
每條手串只有一條，如果剛好被別人先買走了，我會立刻通知你並全額退款。

【關於付款】

目前採銀行轉帳。下單後你會收到轉帳資訊，
匯款完成請回報「帳號末五碼」讓我對帳。

轉帳資訊會在訂單成立時顯示，也會寄到你的信箱。
我確認收到款項後才會出貨，通常是當天或隔天。

【關於出貨】

平日下午三點前確認收款的訂單，當天寄出。
超過的話順延到隔天。週末與國定假日不出貨。

出貨後我會提供物流單號給你查詢。

【關於手圍】

下單前請先量好手圍：拿一條線繞手腕一圈，鬆緊以能塞進一根手指為準，
量出來的長度再加 1～1.5 公分就是適合的手串長度。

不確定的話可以問我，我幫你看。

【關於保養】

天然石怕撞、怕高溫、也怕化學品。
洗手可以不用拔，但洗澡、游泳、擦保養品時請先取下。
彈力繩會隨時間鬆弛，如果覺得鬆了可以找我重穿。
```
