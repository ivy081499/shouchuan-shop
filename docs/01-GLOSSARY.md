# 術語對照

店主用中文思考，程式用英文命名。**沒有固定對照表，五個工作流會發明五種叫法**（bead / stone / material 各寫一套）。

## 核心名詞

| 中文（店主用語） | 程式命名 | 資料表 | 說明 |
|---|---|---|---|
| 珠子／散珠 | `bead` | `beads` | 一顆一顆的材料。**不要叫 stone / material / gem** |
| 手串／手鍊 | `product` | `products` | 前台販售單位。**不要叫 bracelet / item** |
| 配方 | `recipe` | `recipes` | 某手串用了哪些珠、各幾顆 |
| 店鋪／賣家 | `supplier` | `suppliers` | 淘寶店家。**不要叫 shop / vendor / seller** |
| 進貨單 | `purchase` | `purchases` | 一筆淘寶訂單 |
| 進貨明細 | `purchase item` | `purchase_items` | xlsx 的一列 |
| 訂單 | `order` | `orders` | 客戶的訂單 |
| 訂單明細 | `order item` | `order_items` | |
| 庫存流水帳 | `stock ledger` | `stock_ledger` | 庫存增減紀錄 |
| 顆數 | `qty` | | 一律整數。**不要叫 count / amount / number** |
| 單顆成本 | `unitCostCents` | | 整數新台幣分 |
| 售價 | `priceCents` | | 整數新台幣分 |
| 可做數量 | `buildableQty` | | 依配方與庫存算出還能做幾條 |
| 安全庫存 | `reorderPoint` | | 低於此值示警 |
| 待採購 | `shortageQty` | | 還要叫多少貨 |
| 超賣 | `oversold` | | 訂單成立但庫存已不足 |

| 出貨 | 出貨 | 發貨（簡體用語）、寄出 |

## ⚠️ 繁簡規則

- **前台絕對不可出現簡體字。**
- 例外：`purchase_items` 的 `rawTitle` / `rawSpec` 是淘寶原文（簡體），**僅在後台核對介面顯示**，且要標示「淘寶原文」。
- 建立珠子時，`beads.name` 要由店主填繁體名稱，不要直接複製淘寶標題。

## 標點

繁中用全形標點：`，。、；：「」（）`
數字與英文前後不加空格（`NT$980`，不是 `NT$ 980`）。
