# ADR-0002 不串金流，人工確認轉帳

**狀態**：已採用
**日期**：2026-09-11

## 背景

店主明確表示現階段不願為金流付任何費用。台灣的金流服務都有手續費或月費。

## 決策

完全不串接金流。流程改為：

1. 下單後系統產生轉帳資訊（銀行、戶名、帳號、金額、專屬訂單編號）
2. 客戶自行轉帳，回網站填「帳號末五碼 + 轉帳時間」
3. 店主看銀行入帳，核對後在後台按「確認收款」
4. 才出貨

## 後果

**好處**
- 零手續費、零月費
- 沒有金流 API 要維護，也沒有金鑰要保管

**代價**
- 店主必須人工對帳，訂單量大時會是負擔
- 客戶體驗比信用卡結帳差，可能流失衝動型購買
- 無法自動化，訂單成立到出貨的時間拉長

**要注意**
- 系統絕對不可碰信用卡、密碼等付款資訊
- 訂單編號要夠亂（`SC-YYMMDD-XXXX`），避免被猜到別人的訂單
- 日後若要串金流，訂單狀態機已預留空間（`paid` 狀態的來源可改為 webhook）
