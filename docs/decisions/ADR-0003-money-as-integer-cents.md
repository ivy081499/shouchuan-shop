# ADR-0003 金額一律整數新台幣分

**狀態**：已採用
**日期**：2026-09-11

## 背景

系統涉及人民幣進貨成本、匯率換算、運費比例攤提、毛利計算。浮點數在這類連續運算中會累積誤差，最終導致「帳對不起來」。

## 決策

所有金額欄位一律為**整數，單位為新台幣分**。

- `NT$1,280.50` → `128050`
- 匯率存放大 100 倍的整數（`4.5` → `450`）
- 只有顯示時才除以 100
- 統一由 `src/lib/money.ts` 處理轉換與格式化

運費攤提使用 `allocateProportional`，**餘數給最後一項**，保證各項加總等於總額。

## 後果

**好處**
- 不會有 `0.1 + 0.2 !== 0.3` 這類問題
- 攤提後加總必定等於原始總額，帳永遠對得起來

**代價**
- 所有開發者都必須記得單位是「分」，誤用會差 100 倍
- 從使用者輸入取值時一定要經 `yuanToCents`

**強制措施**
- 稽核 subagent 會檢查是否有浮點數金額
- `docs/02-DATA-MODEL.md` 列為鐵律
