# ADR-0010 配方編輯器的選珠介面

**狀態**：已採用
**日期**：2026-09-14

## 背景

店主在 `/admin/products/[id]` 配方編輯器挑珠子時，明確提出四項要求。
這些不是「錦上添花」，是實際用起來會卡住的地方——第一批進貨就有 51 種珠子，
之後只會更多。

## 決策

### 1. 搜尋框

依珠子名稱、尺寸、分類即時過濾。

**已勾選的珠子一律保留在畫面上**，即使不符合搜尋條件。
否則搜尋時已選的珠子會消失，讓人誤以為配方被清掉。

### 2. 分類分組要真的能用

`beads.category` 欄位早就存在，但匯入時沒填，導致所有珠子擠在「未分類」，
分組形同虛設。

改為匯入時呼叫 `inferCategory()`（`src/lib/bead-spec.ts`）自動填入，四類：

| 分類 | 判斷依據 |
|---|---|
| `配件` | 沙金、925銀、包金、鍍金、隔片、花托、轉運珠、桶珠、水泡珠、線圈 |
| `線材` | 彈力線、扁絲、手串繩、繩項鍊（整捲按長度計價的才算）|
| `玉石` | 瑪瑙、玉髓、和田玉、碧玉、曜石 |
| `水晶` | 水晶、月光石、海藍寶、珍珠、貝珠、草莓晶、兔毛、塔晶 |

**「線圈」歸配件不歸線材**（店主 2026-09-15 指正）：桃花線圈是編織好的小圈飾件，
一個一個用，不是整捲按長度剪。線材只留真正按長度計價的（彈力線、扁絲）。

**判斷順序有意義**：配件必須先於線材，線材先於石材。
淘寶商品名常混用字樣——「古法沙金轉運珠…diy手工編織繩配飾掛件」是珠子不是繩子，
若先判斷線材就會分錯。

刻意只分四類。分太細會變成每組一兩顆，失去分組意義。

### 3. 庫存 0 必須可以勾選

店主原話：「我只是上架當然要能選啊」。

上架前備料、先排配方再補貨是正常流程。
**不得因庫存為 0 而禁用勾選、或在儲存時擋下。**
缺貨資訊已由「目前可做」統計與該列的紅字庫存呈現，足夠了。

### 4. 顯示珠子縮圖

沒有圖片時，光看「沙金桶珠 24款」這種名稱認不出是什麼。

- `beads` 表原本**沒有**圖片欄位（`product_images` 是手串成品用的，不是珠子）
- 淘寶匯出的 xlsx **不含圖片網址**，只有商品連結
- 圖片改從淘寶商品頁取得：優先抓該規格自己的縮圖，
  該商品若無規格縮圖則退回主圖

## 後果

匯入流程多一個推導步驟，但店主不必手動分類 51 種珠子。

分類是猜的，可能分錯——`inferCategory` 回傳 `其他` 或分錯時，
店主可在珠子編輯頁自行修正（分類欄位本來就可編輯）。
